## 확인한 한계와 수정

소형 모델의 반복 읽기·요청 되풀이를 실측해, 명시한 파일을 먼저 읽고 읽기 전용 답변은 간단한 별도 문맥으로 생성하도록 보완했다. 한국어 조사가 파일명 뒤에 붙는 경우와 실패한 제안 재시도도 실제 요청으로 발견해 회귀검사에 추가했다. 제안이 만들어진 뒤에는 추가 LLM 추론을 생략하고 실제 미적용·미검증 상태를 앱이 안내한다.

7B도 문장 삽입 위치와 문구를 틀린 제안을 만들었다. 해당 제안은 미리보기에서 확인하여 제외했고 원본은 변경하지 않았다. 자연어 이해·코딩 품질은 완전하지 않다. 제목 교체1건 통과를 복잡한 다중 파일 개발의 정확도로 일반화하지 않는다. 현재 CPU에서는 설명·수정에 수십 초~수분이 걸릴 수 있다.

원본 A3의 Common.Log 누락에 따른 기존 컴파일 오류와 장비 검수는 앱 개발과 별도다. 오프라인 참조 복원은 기존 소스 오류를 고치지 않는다. 다중 PC LAN 서비스, GPU 가속, 모델 재학습, 이미지/스캔 PDF 이해는 이번 구현에 포함하지 않는다. 자체 GGUF 반입은 지원하되 학습과 GGUF 변환은 외부 준비 단계다.
